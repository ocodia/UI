# Fluent system icons

Source: [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons), MIT copyright Microsoft Corporation; see LICENSE.

The 20,239 flattened SVGs were supplied with this workspace. Their original import version and transformation pipeline are unknown; do not describe them as a verbatim upstream release. Their names retain optical size and regular/filled variants. Most paints already use currentColor; intentional fixed colors remain intact.

On 18 October 2026, 5,790 20px variants with a 100 × 100 viewBox had their viewBox and width/height changed to 20 × 20, without changing drawing paths. This follows the 20px coordinate system confirmed against upstream ic_fluent_chevron_down_20_regular.svg at commit a347af95478f989038cccbf085978865264c048a. The remaining file provenance is unverified. tools/build_icons.py --repair-fluent performs only this explicit, repeatable correction and checks for regressions.

The upstream license was retrieved from that commit. Preserve it when redistributing these assets.
