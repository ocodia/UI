Intersection Observer

ui-intersection (optional, proposed)PlannedPhase 5

Expose observation only when repeated product needs justify markup; no essential content depends on visibility callbacks.

Proposed direction

This component is not implemented. Its proposed name is not a registered element or a supported API. There is no live demonstration to initialize.

Use the native or readable baseline described above while the component is specified. Delivery depends on the roadmap and a complete interaction contract.

Acceptance work

Unobserve on disconnect, reconnect once, unsupported API fallback, and nested-root ownership.

Before implementation, specify markup, keyboard/focus behavior, native value ownership, missing-API fallback, late children, nesting and cleanup. APIs, tokens and events will be documented only when implemented.
