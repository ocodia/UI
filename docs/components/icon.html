Load a named SVG from a local library folder. Keep native action labels and useful inline SVG fallbacks.

Implementation maturity: experimental. See dated evidence and remaining release gates.

Dismiss a delivery notice

The native button owns its accessible name and target size. An authored SVG remains visible if the asset cannot load. Dismissal is example application behavior.

Full widthDrag the edge or use arrow keys; Shift changes by 50px. Home/End use minimum/full width.
Code
<script src="js/ui.js" defer></script>
<ui-panel id="delivery-notice">
  <article>
    <h2>Survey export ready</h2>
    <p>Your team can now download the latest observations.</p>
    <a href="../../examples/menu-report.csv" download>Download CSV</a>
    <button id="dismiss-notice" type="button" data-variant="quiet"
            aria-label="Dismiss export notice" hidden>
      <ui-icon name="dismiss-20-regular" aria-hidden="true">
        <svg viewBox="0 0 20 20" aria-hidden="true" focusable="false">
          <path fill="currentColor" d="m5 4 5 5 5-5 1 1-5 5 5 5-1 1-5-5-5 5-1-1 5-5-5-5z"/>
        </svg>
      </ui-icon>
    </button>
  </article>
</ui-panel>
<p id="delivery-status" role="status"></p>
<button id="restore-notice" type="button" data-variant="secondary" hidden>
  Show notice again
</button>
<script>
const notice=document.querySelector('#delivery-notice'), dismiss=document.querySelector('#dismiss-notice'), restore=document.querySelector('#restore-notice'), status=document.querySelector('#delivery-status'); dismiss.hidden=false; dismiss.addEventListener('click',()=>{restore.hidden=false;restore.focus();notice.hidden=true;status.textContent='Export notice dismissed.';}); restore.addEventListener('click',()=>{notice.hidden=false;dismiss.focus();restore.hidden=true;status.textContent='';});
</script>

Keyboard, focus & native state

Icons have no keyboard behavior or focus stop. The containing native link/button owns its accessible name and activation.

Values, validation & fallback

A single authored inline SVG is the optional loading/error/no-script fallback. Observe name/library/label changes; explicitly enhance late icons and destroy before editing fallback content.

Keep labels and instructions available when JavaScript fails. Applications own async work, recovery and server validation. Test disabled, invalid, long-content and loading states where the task supports them.

See the native family state audit for default, long-content, disabled/read-only, invalid, busy and fallback coverage, including states that do not apply.

API & styling

SurfaceContract
nameRequired SVG filename stem, without extension.
libraryLocal folder name; defaults to fluent.
labelOptional meaningful image name; decorative when absent/empty.
data-ui-icons-baseDirectory URL on the shared script; same-origin HTTP(S), trailing slash.
data-ui-icon-stateOwned read-only loading, ready or error state; use explicit enhance to retry errors.
font-size / color1em by default; currentColor artwork inherits text color.

Use the implemented icon contract for the full integration rules and supported cases. Native attributes retain their standard meanings. Only ui-form and ui-error-summary register behavior.

Styles come from css/ui.css in the ui layer. Geometry and semantic colors use UI theme variables. Density and control sizes have separate scopes; they do not apply to every element.

Verification & known limits

Safe SVG subset, local paths, bounded/deduplicated fetch, stale responses, teardown/retry, inherited size/color, meaningful names and fallback. Manual platform/assistive-technology release evidence remains open.

Native/foundation is an implementation route, not a stable-release or accessibility certification. See dated results and unresolved findings; run the browser checks. Manual platform and assistive-technology verification remains part of release readiness.
