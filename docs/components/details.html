Details

details and summaryNative recipePhase 1

Reveal optional supporting content with the browser’s disclosure. The summary remains visible when the content is closed.

Examples

Optional supporting information

Essential instructions belong outside a closed disclosure.

Full widthDrag the edge or use arrow keys; Shift changes by 50px. Home/End use minimum/full width.
Code
<script src="js/ui.js" defer></script>
<details>
  <summary>What happens to my project answers?</summary>
  <p>The application owns storage and server submission. UI keeps native values on the form controls.</p>
</details>

Open example on its own · Form previews send nothing.

Long summary and initially open content

The browser owns open state, Enter/Space activation and focus. Details has no native disabled state; keep essential instructions outside a closed disclosure.

Full widthDrag the edge or use arrow keys; Shift changes by 50px. Home/End use minimum/full width.
Code
<script src="js/ui.js" defer></script>
<details open>
  <summary>Read the complete meeting arrangements, access information and alternative route before joining the coastal field survey</summary>
  <p>Meet at the visitor centre at 09:30. The woodland route is available if the coastal path is closed.</p>
  <a href="#contact">Read the contact information</a>
</details>
<section id="contact"><h2>Contact information</h2><p>Ask the survey coordinator about access before travelling.</p></section>

Open example on its own · Form previews send nothing.

Keyboard, focus & native state

Enter/Space toggles the native summary. The browser owns open state and the toggle event. Required instructions belong outside a closed disclosure. Keep summary text meaningful.

Values, validation & fallback

This primitive does not own application values, persistence or transport. Native descendants retain labels, values and form associations. Keep content readable before optional application behavior initializes.

Keep labels and instructions available when JavaScript fails. Applications own async work, recovery and server validation. Test disabled, invalid, long-content and loading states where the task supports them.

See the native family state audit for default, long-content, disabled/read-only, invalid, busy and fallback coverage, including states that do not apply.

API & styling

SurfaceContract
openNative Boolean disclosure state.
toggleNative state-change event. Do not synthesize it during initial rendering.
summaryThe first summary supplies the disclosure label and activation target.

Use the implemented reference contract for the full integration rules and supported cases. Native attributes retain their standard meanings. Only ui-form and ui-error-summary register behavior.

Styles come from css/ui.css in the ui layer. Geometry and semantic colors use UI theme variables. Density and control sizes have separate scopes; they do not apply to every element.

Verification & known limits

Enter/Space, open state, link targets, print policy, and nested disclosure behavior.

Native/foundation is an implementation route, not a stable-release or accessibility certification. See dated results and unresolved findings; run the browser checks. Manual platform and assistive-technology verification remains part of release readiness.
