Components / Forms

Checkbox

input[type=checkbox]Native recipePhase 1

A checkbox toggles an independent choice. Several checkboxes can collect multiple answers to one question; an indeterminate appearance can represent a partial selection.

Examples

Single choice

Full widthDrag the edge or use arrow keys; Shift changes by 50px. Home/End use minimum/full width.
Code
<label><input type="checkbox" name="updates" value="yes"> Email me project updates</label>

Open example on its own · Form previews send nothing.

Checked, hint and disabled

Full widthDrag the edge or use arrow keys; Shift changes by 50px. Home/End use minimum/full width.
Code
<ui-stack>
  <ui-field><label><input type="checkbox" name="news" value="yes" checked aria-describedby="news-hint"> Project news</label><ui-hint id="news-hint">You can change this later.</ui-hint></ui-field>
  <label><input type="checkbox" disabled> Updates are unavailable</label>
</ui-stack>

Open example on its own · Form previews send nothing.

Indeterminate state

Indeterminate is a JavaScript property, independent of checked. A real select-all operation must coordinate its child checkboxes.

Full widthDrag the edge or use arrow keys; Shift changes by 50px. Home/End use minimum/full width.
Code
<label><input id="all" type="checkbox"> Select all project chapters</label>
<script>
document.querySelector('#all').indeterminate = true;
</script>

Open example on its own · Form previews send nothing.

Required choice and error recovery

Full widthDrag the edge or use arrow keys; Shift changes by 50px. Home/End use minimum/full width.
Code
<ui-form>
  <form>
    <ui-field><label><input type="checkbox" name="confirmation" value="yes" required> I have checked the project details</label><ui-error hidden>Error: Confirm you checked the project details</ui-error></ui-field>
    <button type="submit">Check confirmation</button>
  </form>
</ui-form>

Open example on its own · Form previews send nothing.

Keyboard, focus & native state

Space toggles the focused checkbox. Use its checked property for current state; checked markup sets the reset default. Indeterminate is separate and must be set with JavaScript.

Values, validation & fallback

Only checked, enabled, named checkboxes serialize. An omitted value serializes as on; provide a meaningful value. Required applies to this checkbox, not a whole group.

Keep labels and instructions available when JavaScript fails. Applications own async work, recovery and server validation. Test disabled, invalid, long-content and loading states where the task supports them.

See the native family state audit for default, long-content, disabled/read-only, invalid, busy and fallback coverage, including states that do not apply.

API & styling

SurfaceContract
name / valueUse a meaningful form key and answer. An enabled successful native control contributes its value.
disabledBoolean presence disables interaction and excludes the control from form submission.
requiredWhere supported, the native control must satisfy its missing-value constraint before submission.
formAssociate with a native form by ID when outside its subtree. Labels and DOM layout stay independent of ownership.
aria-describedbySpace-separated hint/error IDs. Preserve existing descriptions when adding feedback.
checked / defaultCheckedchecked is the current Boolean property; checked markup sets the reset default.
indeterminateJavaScript-only property; changes appearance independently of checked. It is not a custom HTML attribute.
valueDefaults to on when omitted. Only a checked, enabled checkbox contributes it.

Use the implemented forms contract for the full integration rules and supported cases. Native attributes retain their standard meanings. Only ui-form and ui-error-summary register behavior.

Styles come from css/ui.css in the ui layer. Geometry and semantic colors use UI theme variables. Density and control sizes have separate scopes; they do not apply to every element.

Catalogue markup

This minimal structure describes the route. Live examples above add the context needed to try it.

Minimal markup
<label><input type="checkbox" name="updates" value="yes"> Email updates</label>

Verification & known limits

Space toggles; indeterminate is separate from checked; field errors remain associated.

Native/foundation is an implementation route, not a stable-release or accessibility certification. See dated results and unresolved findings; run the browser checks. Manual platform and assistive-technology verification remains part of release readiness.
