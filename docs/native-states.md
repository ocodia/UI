# Native family states

This is the Phase 1 audit of authored examples, not a stable-component checklist. Native/foundation status and the remaining manual/platform release gates are unchanged. Component pages contain runnable previews and their exact source; larger recipes cover workflows that do not fit a short sample.

## Shared rules

Labels and hints remain visible before validation. Optional ui-form enhancement adds linked error text on submission and preserves the native control as the value owner. Reset restores authored defaults and clears managed errors. Supported read-only answers remain successful form entries; disabled controls do not. No state example grants authorization or replaces server validation.

Busy belongs to an operation, not every control. Use the [working async recipe](../examples/form-integration.html) for one announcement owner, persistent failure feedback, duplicate-submit prevention, cancellation, retry and stale-response handling. Do not add aria-busy to static sample content or invent feedback component APIs. Static loading/error panels illustrate content only.

Without scripts, preview-only inspection actions stay hidden, native controls remain available, and forms retain native constraint validation. Those preview forms have no server action; the no-script explanation makes that limit visible. Production applications must supply a real destination or install their own handler before enabling local-only actions.

## Verification and remaining work

The [browser harness](../tests/accessibility.html) exercises the new previews' required/bounds/step recovery, native values and reset, disabled omission, disclosure state, destinations, and 320px LTR/RTL reflow with and without scripts. Reflow checks also use doubled root text and expanded text spacing across default/forest and light/dark modes. These are simulations, not actual browser zoom or native picker coverage. Read [dated results](../ACCESSIBILITY.md) for which browser and checks actually ran.

Remaining Phase 1 work includes cross-browser/mobile pickers, native option truncation and selection gestures, additional dialog platform/assistive-technology coverage, real screen-reader announcements, touch targets, actual zoom/text spacing, Windows contrast themes and print review. Resolve the existing manual audit findings and legacy media captions/transcripts. Authored state coverage does not close these release gates.
