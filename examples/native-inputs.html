    Submitted entries

    Entries below come from native FormData, including repeated names and the submit button. An empty file selection contributes an empty File entry. This is a local inspection; no upload or booking takes place.

    Server responsibilities

    Recheck dates, time intervals, allowed choices, file counts and sizes, and range bounds. Treat the date as a calendar date; resolve the local time using the venue's trusted timezone and an explicit daylight-saving policy. Read-only and disabled presentation provides no authorization.

    The accept attribute only guides the picker. A real upload service must inspect file content and type, enforce limits and access rules, and handle safe storage. A rejected response preserves other answers and explains when files need to be selected again.
